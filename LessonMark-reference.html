LessonMark Reference

Every feature and its notation: what it does, and exactly how to write it.

Setup files and loading

The folder

  • index.html: the page. Never needs editing.
  • data.md: the lesson (plain text, UTF-8).
  • Media and images used by the lesson: audio.mp3, video.mp4, image01.png…
  • Upload the whole folder to the website.

How the lesson is loaded

  • The page opens data.md automatically.
  • Other lessons: index.html?lesson=venice.md
  • No file found: an Open a lesson screen to choose or drag a file in.
  • Opened by double-click: browsers block the automatic load, so choose the file. Audio, video and images still work; YouTube usually doesn't.
  • Open in the top bar loads another lesson at any time.

General rules

  • Tags are in square brackets and start at the beginning of a line.
  • One-line tags end on the same line: [tf] … [f], [img …]. Block tags close with [/tag]; a short block can open and close on one line.
  • * marks the correct option · = introduces an answer · | separates accepted alternatives.
  • Text in "double quotes" inside a tag is a caption, title, name or label.
  • Curly brackets always make a gap. For literal symbols write \{ \} \[ \].
  • Times: mm:ss or hh:mm:ss (decimals allowed: 01:23.5).
  • Empty lines separate paragraphs. Inside block tags, empty lines are ignored.

What happens automatically

Numbering and navigation

  • Every ## section is numbered and listed in the sticky top menu.
  • Items and gaps are numbered 1, 2, 3… inside each section.
  • Activities written before any ## get their own untitled section.

Checking

  • Check answers marks each answer green or red and shows a score.
  • Show answers fills in every answer (in blue). Clear resets.
  • Ignored when checking: capitals, accents, curly vs straight apostrophes, extra spaces, final punctuation.

Help and answer key

  • Need help? Word bank: folded, alphabetical list of the answers under any section with typed gaps or short answers (not when [bank] is used).
  • Answer key: folded at the end of the page, grouped by section.

Safety nets

  • Mistakes in data.md appear in a red box with the line number.
  • Missing image: “Cannot find … in this folder”. Missing media: red message in the player.
  • Shuffled lists never appear already in the right order.

Troubleshooting

ProblemFix
“Open a lesson” screenNo data.md next to the page, or the page was opened by double-click. Upload the folder, or choose the file.
YouTube won't playPut the page online; use “Open on YouTube” meanwhile.
A gap appears where it shouldn'tCurly brackets in normal text. Write \{ and \}.
Red box: “not closed”A block tag is missing its [/tag].
Transparent PNG shows a boxPage opened from disk. Add transparent to the [img] line.
Black drawing invisible in dark modeUse mid-tone colours in transparent images.
